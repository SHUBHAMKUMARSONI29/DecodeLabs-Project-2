# Responsive Web Layout - Frontend Development Project 2

## 📌 About

This project is part of Frontend Development Project 2.

The main objective is to create a responsive webpage that works properly
on mobile, tablet and desktop screens.

## 🎯 Objectives

- Create a responsive webpage
- Use mobile-first design
- Use CSS Media Queries
- Implement responsive navigation
- Use Flexbox
- Use CSS Grid
- Use fluid typography
- Create touch-friendly buttons
- Follow basic accessibility practices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📱 Responsive Breakpoints

- Mobile: Default layout
- Tablet: 768px
- Desktop: 1024px

## ✨ Features

- Responsive navigation
- Hamburger menu on mobile
- Mobile-first CSS
- CSS Grid layouts
- Flexbox components
- Responsive typography using clamp()
- Touch-friendly buttons
- Responsive cards
- Accessible navigation

1. Download or clone the repository.
2. Open the project folder.
